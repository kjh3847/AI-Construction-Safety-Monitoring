# 시스템팀 계정 발급 프로그램

## Windows EXE

실행 파일은 소스 PR과 분리해 검증 후 GitHub Release의 첨부 파일 등으로 배포한다.
현재 ZIP 작업본의 `dist\SafetyAccountAdmin-cloud.exe`는 보존하며 이 PR에 포함하지 않는다.
이 PR 소스로 재빌드·검증한 EXE를 별도 배포해야 한다. Python 설치 없이 실행 가능하다.
이 파일은 계정 발급 클라이언트만 포함한다. API 서버는 별도로 실행해야 한다.
기존 v3 EXE에서는 API 서버 주소를 https://safety-capstone-2026.duckdns.org 로 변경한다.
서비스 웹 주소는 현재 서버 설정에 맞춰 http://localhost:5173 을 유지한다.
소스 실행 시에는 위 HTTPS API가 기본값이다. 다른 PC에서는 배포된
공통 HTTPS API 주소와 서버 PUBLIC_APP_URL에 해당하는 서비스 웹 주소를 입력한다.
RDS 암호, Brevo 키, RDS 인증서 파일은 EXE에 포함하지 않는다.
외부 배포용 코드 서명은 아직 적용하지 않았다.

계정 관리: 목록에서 계정을 선택하고 '계정 비활성화'를 누르면 사유 입력과
확인 후 로그인이 차단되고 기존 세션이 종료된다. '계정 영구 삭제'는 비활성화된
일반 관리자 계정만 처리할 수 있으며, 사유 입력과 최종 확인이 필요하다.
계정/세션 정보는 삭제하지만 account_audit의 담당자·사원번호·사유·시각은 보존한다.
시스템팀 계정은 두 기능 모두 차단한다. 이 버전 사용 전 API 서버를 재시작해야 한다.

재빌드: 프로젝트 가상환경에 PyInstaller를 설치한 후
`powershell -ExecutionPolicy Bypass -File ".\관리자 계정 생성\build_exe.ps1"`.
저장소 루트 기준이다. 다운로드 작업공간의 형제 폴더 배치도 지원한다.

DB에 직접 연결하지 않고 공통 계정 API를 호출한다. RDS 마스터 암호와 Brevo 키는
API 서버 실행 시만 입력한다. 데스크톱 앱에는 넣지 않는다.

## 실행 (VS Code, PowerShell)

저장소 루트에서:

1. 계정 서버 실행:
   `.\.venv-accounts\Scripts\python.exe backend\run_accounts.py`
   기존 RDS 주소라면 Enter, DB 사용자도 postgres라면 Enter 후 마스터 암호 입력.
   최초 실행이면 시스템팀 사원번호/이메일/새 비밀번호를 입력해 계정 생성.
   Brevo 키는 입력하거나 Enter로 건너뛴다. 키를 건너뛰면 계정 생성 요청은
   발급 대기로 남고 이메일 발송은 성공하지 않는다.
2. 별도 터미널에서 데스크톱 실행:
   `.\.venv-accounts\Scripts\python.exe ".\관리자 계정 생성\main.py"`
3. 서버 주소와 서비스 웹 주소는 기본값 유지 후 생성한 시스템팀 계정으로 로그인.
4. 발급할 사원번호/이메일 입력 → 계정 생성 및 이메일 발송.
   실패 시 목록 새로고침으로 발급 대기 계정을 확인하고, 서버 이메일 설정 후 재전송.
5. 메인 웹 로그인은 별도 터미널의 `npm run dev` 후 http://localhost:5173 에서 확인.

서비스 웹 주소는 서버 PUBLIC_APP_URL과 같아야 한다. 원격 배포 시 API는 HTTPS.
발급된 일반 관리자는 데스크톱에 로그인할 수 없으며 메인 웹에서 로그인한다.
임시 비밀번호는 이메일로만 전달하고, 첫 로그인에서는 비밀번호 변경을 강제한다.
비밀번호 변경은 기존 로그인 세션을 모두 종료한다.

현재 원격 API 서버 배포와 실제 Brevo 발송 검증은 별도 작업이다.
메인 대시보드의 영상 서버(8002)는 별도로 실행해야 한다.
